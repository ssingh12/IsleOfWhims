# Isle of Whims

A party game prototype. Each player is a minor god with a secret fate in mind. The creatures on the island think for themselves; the gods can only nudge.

Play it at **https://ssingh12.github.io/isleofwhims/** once GitHub Pages is switched on.

- **Deal the fates**: pass one screen round the table.
- **Play with phones**: each player scans a QR code and uses their phone as a private controller. No accounts needed. Phones connect directly to the main screen through [PeerJS](https://peerjs.com/).
